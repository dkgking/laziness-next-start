# Text and languages

- The app is English-only unless the user asks for other languages; then follow `.claude/skills/add-locale/SKILL.md`.
- Every visible string (text, `placeholder`, `alt`, `aria-label`, titles) goes through `i18n._("Full English sentence", { values })`. The variable is always named `i18n`: in a Server Component `const i18n = i18nFor(locale)` (`#/libs/i18n-server`), in a Client Component `const { i18n } = useLingui()` (`@lingui/react`).
- Module-level labels are descriptors marked for extraction: `/*i18n*/ { id: "Home" }`, rendered with `i18n._(descriptor)`. No Lingui macros (`msg`, `t`, `<Trans>`): this app compiles none. No concatenation or template strings.
- Numbers and dates go through `#/libs/intl` (`formatDate(i18n.locale, value)`).
- After changing text: `bun run i18n:extract`; with other locales, fill every catalog, then `bun run i18n:check`.
- Full rules: `.claude/skills/i18n-lingui/SKILL.md`.
